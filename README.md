# Jasmine Driving Game

A single-file browser driving game with a four-lane freeway, city traffic, traffic lights, parking, synthesized sound, and a rear-view reverse camera. No build step or external assets are required.

## GitHub Pages

The GitHub Actions workflow deploys the root of `main`. In this repository, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions** if it is not already selected. Future pushes to `main` deploy automatically.
